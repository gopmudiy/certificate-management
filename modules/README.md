# AI Operations Workshop

## Modules

### Module 1: Certificate Management with Bedrock AgentCore
Deploy an AI agent that automates TLS/SSL certificate lifecycle (scan, renew, store).
- Deploy agent to AgentCore Runtime
- Invoke via natural language
- Proactive monitoring with EventBridge + SNS

### Module 2: Bedrock Cost, Security & Resiliency
Build a Knowledge Base from Amazon SEC filings and apply production patterns:
- Cost: Prompt Router, AIP, Caching, Batch, Distillation
- Security: Guardrails, Input/Output Validation, Rate Limiting
- Resiliency: Retry, Circuit Breaker, Fallback Chain
- Operations: CloudWatch Dashboard, Cost Budgets

### Module 3: AgentCore Operations
Operational patterns for AgentCore Runtime:
- Session lifecycle management (idle timeout, explicit stop)
- Tool result caching
- Cold start vs warm sessions
- Guardrails in agent code
- Blue/green deployment
